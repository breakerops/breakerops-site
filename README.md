# breakerops-site

Static site for breakerops.com, hosted on GitHub Pages. BreakerOps keeps records of dates and numbers small business owners need to remember (licenses, certifications, worker overtime) and reminds them when they matter.

Pages: index.html, what-we-do.html, how-it-works.html, contact.html. Styles in assets/css, images in assets/img.

Copy rules:
- No fake testimonials, client logos or invented numbers.
- No guarantees. We only know what the customer tells us.
- No legal, tax, insurance or payroll advice claims.
- No customer SMS number until text sending is provisioned.
- Replies and confirmations are handled by us, not by an instant automatic system.

Backend and customer data do not belong in this public repo.
